# 游戏检查与修复记录

本轮检查覆盖当前 `map` 项目的游戏流程，已复现并修复以下问题。

| 问题 | 复现方式 | 修复 |
| --- | --- | --- |
| 地图下拉框与实际大陆不一致 | 按数字键切换大陆 | 订阅大陆变化，同步下拉框选择 |
| 进出地点后日期消失 | 出生点进入祭坛，或离开特殊地点 | 日期与地点分别维护，再统一显示；忽略其他角色的地点事件 |
| 仪式跳过白天校验 | 夜晚读条时点击“推进一天” | 每一次时段变化均立即验证，而非只检查下一物理帧的最终时段 |
| 神力跨大陆误伤 | 不同大陆角色恰好具有相近坐标 | 范围伤害要求区域标签一致，且目标仍存活 |
| 角色移除后注册残留 | 释放已登记玩家节点 | 节点退出时清理玩家、仪式和快照；旧节点退出不会清理同ID的新角色 |

额外拒绝空角色注册和非有限伤害值，防止异常数据破坏血量。

## 验证

- `GameBugRegressionTest.gd`：12项边界检查。
- `CharacterInfoUITest.gd`：21项UI输入检查。
- `ProgressionIntegrationTest.gd`：33项职业与成神检查。
- 原有大陆切换、六张命名地图、外观、相机及墙体碰撞测试。

以上测试在 Godot 4.3 执行通过；同时检查 Godot 4.7.2 的边界回归及实际渲染。
测试覆盖不等于保证不存在其他问题；当前项目仍是单玩家地图演示，真实联网会话、存档和复活尚未实现。
