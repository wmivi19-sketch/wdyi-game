God Gifted Mountains Pixel v1
Install this entire folder under Wonderdraft/assets.
Enable God_Gifted_Mountains_Pixel_v1 in the map Assets dialog, save and reopen the map.
Categories start with GGM_. All assets use normal draw mode to preserve colors.
Roads and cliff pieces are symbols, not seamless terrain or road brushes.
Original atlas alpha edges are preserved around extracted silhouettes.
