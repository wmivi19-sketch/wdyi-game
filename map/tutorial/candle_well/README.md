# 烛井：独立新手关

入口修正：出生甬道正对的南侧现有可通行的入口坡阶，南侧扶手图形与碰撞均留开口。可从实际进入的位置继续攀登，沿上升方向抵达标注“上层”的出口后自动换层；不再要求从隐蔽的东侧起始点累计一整圈。靠内缘或外缘正常行走不会丢失进度。中层会按第一次实际沿阶移动方向判断上楼/下楼，站着不动不会传送。原 E 平台换层保留。

楼梯现支持沿台阶行走自动换层：东侧低端进入，沿一整圈上升后进入下一层；从高端反向行走可以返回上一层。换层落在平台外侧安全通道，设置冷却，避免站在落点时反复传送。原有 E 平台交互保留兼容。石柱/内缘使用 StaticBody2D + CircleShape2D，外侧扶手沿弧线设置有厚度的 CollisionPolygon2D，东、西平台口留通道；不会把整条可行走楼梯封成实心障碍。

中央现为完整一圈的石质螺旋楼梯：32 级扇形踏步围绕粗石立柱盘旋，逐级升高至 64 画面像素，带踏步立面、磨损缺口、旧铁扶手及平台开口。三层共用同轴位置，沿用原来的 E 上下楼交互。人物脚底按所在踏步升降；核心石柱保留阻挡，靠近时局部淡出以避免遮住角色。二维上下层仍使用明确的场景跃迁，非三维连续坡面。专项测试见 `tests/SpiralStairTest.gd`。

正式入口仍为 `project.godot` 的原始主菜单。点击新游戏进入 `scenes/TutorialCandleWell.tscn`，通关后交回菜单配置中的 `navigation.game_scene`，默认 `scenes/MapDemo.tscn`。

烛井不注册到 MapDatabase，不占用六大陆索引，也不修改大陆地图。新手关时 GameState.current_continent 为空，区域标记为 tutorial_candle_well；GameManager 的大陆战斗模拟关闭，因此不推进十四日生存进程。六玩家和原有职业、交易、共享背包初始化仍由原世界场景完成。

教学完成条件：从底层沿楼梯到顶层，进入天窗竖井落回中层东南密室，在室内按 E 打开 G4，再返回中层中央平台北侧 `(32,27)` 附近按 E。其余四裂板和五宝箱为可练习支线，不强迫新手全收集。

WASD / 方向键移动；E 操作楼梯、宝箱、开关及三次敲碎裂板；F5 保存；F10 保存并返回菜单；R 重置当前教学进度。默认启用偏冷的低饱和环境调制，三层的人物、道路和机关均可见，整体保持阴暗风格。顶层蜡烛保留局部光照和阴影；F1 为可选亮度辅助，切回时也不会变成全黑。此设置取代最初的严格全黑要求。

新手关使用现有存档槽，写入带 `stage: tutorial_candle_well` 的独立有效载荷，包含楼层、精确地面位置、裂板/敲击、宝箱、闸门和天窗完成状态。继续游戏按载荷恢复新手关或直接恢复旧式大陆存档。新开局不擅自覆盖旧磁盘存档；保存操作先写临时文件再原子替换。

渲染为 2D 斜俯视像素场景；物理仍使用 16px 地面坐标。临时启用低分辨率视口，退出时恢复原菜单/大陆的视口设置和背景色。教学中的宝箱仅记录教学探索进度，不伪造正式物品奖励，正式共享库存仍由已有 WorldItems 创建。

相关验证：`tests/TutorialIntegrationTest.gd`、`tests/MainMenuTest.gd`、`tests/MapCombatIntegrationTest.gd`、`tests/GameBugRegressionTest.gd`。实际截图工具为 `tests/CaptureTutorial.gd`，鼠标点击菜单冒烟测试为 `tests/NewGameSmoke.gd`。测试运行使用隔离的 user:// 子目录。
