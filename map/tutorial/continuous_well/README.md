# 烛井：连续圆弧旋梯修订版

本版为《逐神终焉》当前初始关：独立于六大陆，2D像素斜俯视，人物局部跟随镜头。默认画面能辨认地面、人物、台阶和墙体；保留低饱和暗灰、灰褐与石青色调。

## 中央楼梯

中央石柱轴线垂直贯穿L0/L1/L2，逻辑中心(512,256)，高度0/128/256。楼梯绕柱连续盘旋两整圈，每圈48条窄石踏步，总96条，划分成12个逻辑扇区供高度/触发索引使用。**逻辑扇区不画成六边形折线路段**。

内侧视觉半径62、外侧100、石柱视觉半径58；柱碰撞半径60，外护缘实体100–108。每层都有单独的64×64逻辑像素石质平台(30,21,4,4)，南侧接中央大厅；平台两侧预留连接周边房间的通道。踏步外唇有磨损缺角，石柱有凿痕和错缝，缺角只改变画面，不挖开通行碰撞。

三层从首帧常驻；每个扇区Area2D仍由精确16×16格占用组成。玩家在梯上时用相对于中心的实际极角解算连续相位，再选最接近上一帧的圈数；高度Z=phase×256/12，phase范围0–12。正反行走均连续，不卡在扇区边界，无场景重载、黑屏、楼层传送。

视觉投影为C+(project(XY)−C)×(1+Z/256×0.035)+(0,−1.10Z)，C=(1280,384)。Z不再产生水平偏移，因此石柱始终为竖直轴。2D角色仍使用Vector2地面坐标，Z是独立逻辑参数，不能写Node2D.position.z。

后半圈踏步画序160、柱170、前半圈踏步180、平台181、玻璃182。梯上角色后方165、前方185；角色绕到柱后时柱透明度平滑降至0.28，便于观察，碰撞保持。镜头默认zoom=1.15，随高度最多增加0.035，展示玩家附近区域；全梯截图单独使用0.68的诊断镜头，不是默认全图摄像机。

## 照明

默认CanvasModulate=(0.92,0.94,0.96)，所有高度保持可读。纯黑视野遮罩默认关闭，不需要F1。地板基础颜色约#4b5353–#5c625a；石阶约#77816f–#818979，阴影和描边仍用低饱和深灰。

顶层唯一PointLight2D烛光保留，位置(32,16)，energy=1.15、512px径向纹理、texture_scale=1.4、PCF5阴影；它承担局部暖色重点照明。环境光负责整体可读性，所以远处不再被强制压为纯黑。F1仅作为观察辅助。

## 主探索闭环

L0东入口(60,16)→中央南平台→沿圆弧旋梯到L1平台→继续到L2平台→东侧画廊→天窗竖井SKY→直接下落到L1东隐藏室(54,26)→内开G4→回中央楼梯向下行走→L0东出口按E进入原大陆流程。

SKY区域L2(52,24,4,4)，与中层东隐藏室上下对齐。走出平台边缘或跳入区域即开始连续下落，不需要先敲碎地板，也没有手动切层。L2东画廊和天窗平台、西侧裂板小室补入了真实地面及碰撞，连接中央顶层空间。

## 四处裂板：每块均直接落到下一层

坐标从0开始；矩形为(x,y,w,h)，单位16px格。

|裂板|所在层与触发矩形|安全落点|高度差|
|---|---|---|---|
|B1|L1 (10,24,4,4)|L0 (12,26)|−128|
|B2|L1 (9,4,4,4)|L0 (11,6)|−128|
|B3|L2 (34,24,4,4)|L1 (36,26)|−128|
|B4|L2 (15,23,4,4)|L1 (16,26)|−128|

中层和顶层各2块；所有落点在对应裂板的平面投影内，下层有可站立地面，并避开下层裂板/天窗，防止连锁掉层。三次E敲击破碎，边缘和板面预先画分叉裂纹。B1位于L1西侧隐藏小室，可从B4支路进入后继续落到L0奖励室。B2不再进入同层夹道，直接落到L0北侧安全房。

B3与SKY为两个独立入口：B3是普通裂板，SKY是主闭环直接跃下区域；只有SKY落地记录主线天窗返回事件。落下时重力600逻辑px/s²，目标XY仅在洞口范围内向安全格中心收敛，mask临时为0；落到目标高度和位置后恢复对应层墙体碰撞。

## 宝箱与玻璃

5箱保持L0两箱、L1两箱、L2一箱：C1(12,26)、C2(12,6)、C3(16,26)、C4(54,26)、C5(42,6)。C1/C3/C4在掉落奖励区；C3已避开B1裂洞，拿奖励时不会再掉层。

三处一次性玻璃保留：GL1=(31,20,2,2),Z0；GL2同XY,Z128；GL3=(50,25,2,2),Z256，在天窗前的石质踏面。首次落脚播放6帧/12fps动画及14块碎片，落地2秒清除；永久石阶支撑保留，存档记录一次性状态。玻璃不会代替B3裂板或SKY触发器。

## Wonderdraft与Godot交付

地图仍为64×32个16px逻辑格，每层地形PNG1024×512，另附透明碰撞、交互、圆弧楼梯路径图。三张等距原理图含右侧坐标与动线面板。等距屏幕菱形瓦片为32×16px，16×16指地面逻辑网格，两者不要混用。

Wonderdraft按1024×512画布、16px网格、1×导出；PNG不携带引擎碰撞体。Godot既有实现读取dungeon.json、stair_path.json与glass_platforms.json构造场景；不把整张原理图当TileMap贴图。需要TileMapLayer时设Isometric、Stacked、Vertical Offset、tile_size=(32,16)、Nearest过滤、Y Sort，保持相同投影与脚点原点。

正式入口仍为scenes/TutorialCandleWell.tscn，基类tutorial/continuous_well/world.gd。玩家layer8、楼层墙1/2/4、梯实体16；平地mask=(1<<楼层)|16，梯上mask16。单场景示例main.tscn可直接运行，用于观察连续旋梯、玻璃与掉落；正式菜单和大陆系统在正式游戏中。

旧存档保留原校验与迁移。裂板/宝箱/玻璃编号保持连续，L0东出口和大陆入口流程不变。测试覆盖完整上下梯、全部4个向下落点、SKY直接跃下、玻璃一次性效果、存档与原菜单大陆流程，详细结果见验证与部署记录.json。

原理图是编辑全图；“实机”文件来自Godot实际GPU渲染。entry_default和各高度截图使用默认照明与人物镜头；three-floor_stair_overview是只为检查三层楼梯完整性而拉远的诊断视图。


## 当前版：入口移动与地图优化

玩家控制器同时识别物理键码和普通键码；WASD/方向键均按屏幕方向移动。E和保存等快捷键同样支持普通键码。屏幕输入单位向量(sx,sy)反投影为地面向量(sx/2+sy,sy−sx/2)，保持屏幕行走速度120px/s。角色motion_mode=MOTION_MODE_FLOATING，让俯视碰撞等向滑动，不把墙面当平台坡面。

东入口新增10×13格前厅(52,10,10,13)，初始站位改为(57,16)，主通道由5格加宽为7格(8,13,54,7)。东出口仍是(60,16)。地面石纹依次引导到中央南平台。顶部显示层名、宝箱和操作，不再以技术高度数字占据主要提示。

旧教学存档如果位于原入口附近且未解锁机关/奖励，会迁至新入口内部的安全站位；其余存档位置继续保留。楼梯相位先比较未截断的相邻圈候选，再将最终结果钳位到0–12，避免从顶层平台稍偏一侧进入时跳回中层。

EntryMobilityTest的39项检查逐一覆盖物理/普通键码、WASD/方向键、松键停止、屏幕方向、普通E交互、浮动碰撞、初始站位及两个楼梯端点。完整楼梯75项和地图22项均实走；底层入口操作已在GPU画面中使用普通键码四向移动验证，截图脚本没有关闭玩家物理处理。


## 跳跃与裂板接触

破碎裂板在玩家跳跃期间不提供支撑，也不会在玩家仍腾空时提前触发跌落；角色落回该区域后自动下落。跳跃时敲击地板同样不计为落地踩击。天窗SKY为独立的主动跃下入口，仍接受空中进入。回归测试见tests/TutorialFloorJumpTest.gd。
