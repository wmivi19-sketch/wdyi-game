# 人物与美术替换测试

按 F5 运行项目。人物位于中央通道，默认使用原创 SVG 占位人物，适合测试比例、移动和遮挡。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 在地面上移动 |
| Shift | 加速 |
| 空格 | 跳跃，可跳上祭坛平台 |
| R | 回到中央通道起点 |
| 左上角「更换人物贴图…」 | 从电脑选择 PNG、WebP、JPG 或 SVG |
| 「恢复测试人物」 | 恢复默认占位素材 |

运行中换图只对本次运行生效，不修改原始图片。建议使用带透明背景、单个人物完整立绘的 PNG；当前控制器使用静态图片、左右翻转和轻微移动起伏，不会把动画图集自动拆帧。

## 永久替换人物美术

在 `main.tscn` 中选择 `TestPlayer`，修改「人物美术」：

- **Character Texture**：拖入人物贴图。
- **Art Height**：显示高度，默认 2.1 米，按图片非透明区域归一化。
- **Art Tint**：颜色乘数。

也可打开 `scenes/test_player.tscn` 修改所有实例的默认设置。人物脚底自动对齐根节点；贴图水平镜像后仍保持对齐。

人物的胶囊碰撞体与美术独立，默认半径 0.3 米、高度 1.6 米。替换图片、修改美术高度都不改变碰撞；如需改变碰撞尺寸，编辑 `TestPlayer/CollisionShape3D` 的胶囊资源。角色位于碰撞层 2，检测场景碰撞层 1。

场景元素的美术仍可在 `cathedral.tscn` 中选择对应元素，修改模板的 Texture、Size Scale 和 Tint。
