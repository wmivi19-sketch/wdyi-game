# HD-2D 场景元素模板

主场景：`res://scenes/main.tscn`，已设为项目启动场景，按 **F6** 预览当前场景，**F5** 启动项目。

2026-10-26 更新：启动场景现已替换为参考图教堂布局。请打开 `res://scenes/cathedral.tscn` 进行元素编辑，详细结构见《教堂场景说明.md》。下文的参数说明仍适用；早期单石柱主场景说明仅记录模板初始示例。

模板：`res://scenes/scene_element.tscn`。采用固定朝向的 Sprite3D + StaticBody3D，适合在 3D 场景中摆放透明 PNG 建筑、石柱、树木等立面素材。

## 添加元素

1. 打开主场景，把 `scene_element.tscn` 从文件系统拖入 `Elements` 节点，创建一个实例。
2. 选中实例根节点，在检查器「贴图与尺寸」的 **Texture** 中拖入 PNG。
3. 调整 **Pixel Size**（每像素米数）和 **Size Scale**（宽、高倍率）。例如 1000 像素宽的图片，Pixel Size 为 0.01 时宽 10 米。
4. 在 3D 视口移动根节点；下中中心点默认位于可见图形底边中点，放到地面高度即可落地。
5. 复制实例可以继续摆放。实例参数和碰撞资源彼此独立，无需开启「可编辑子节点」。

## 快速设置

| 检查器字段 | 作用 |
| --- | --- |
| Texture | 导入/替换贴图，自动读取图片尺寸与透明外轮廓 |
| Pixel Size | 像素到世界单位的换算比例 |
| Size Scale | 宽、高缩放倍率；画面、碰撞与中心偏移同步更新 |
| Pivot | 左上、上中、右上、左中、居中、右中、左下、下中、右下 |
| Trim Transparent Border | 默认开启，以可见内容而非透明画布的边缘定位 |
| Pivot Offset Pixels | 中心点微调；X 向右，Y 向下，单位原图像素 |
| Flip H / Flip V | 水平/垂直镜像；碰撞一起镜像，九宫格位置按镜像后的可见边界计算 |
| Collision Mode | 透明外轮廓、可见边界矩形、关闭 |
| Collision Depth | 外轮廓沿 Z 轴的厚度（米），随 Size Scale.x 缩放 |
| Collision Layer / Mask | 标准 Godot 3D 碰撞层和检测掩码 |
| Alpha Threshold | 默认 0.1，忽略低透明度像素；同时用于显示裁切 |
| Outline Simplification | 轮廓简化精度，默认 3 原图像素；较大时顶点更少 |
| Receive Lighting | 是否接受环境光与方向光 |
| Tint | 元素的颜色乘数，用于统一明暗与色温 |
| 重新识别贴图与碰撞 | 强制刷新；一般修改属性会自动更新 |

中心点是实例根节点的原点，因此移动、旋转与 Size Scale 缩放都以该点为基准。修改中心点会改变图像相对于原点的位置。建议保持根节点及父节点的 Transform Scale 为 `(1,1,1)`，使用 **Size Scale** 调整大小，避免 Godot 物理节点的非均匀缩放问题。

## 自动碰撞的工作方式

脚本在编辑器和运行时执行，读取 alpha 遮罩，提取外轮廓，创建具有厚度的 `CollisionPolygon3D`。碰撞尺寸由缩放后的坐标直接生成，物理节点本身维持单位缩放。更换贴图或透明度阈值时重新识别轮廓，移动或缩放时复用识别结果。

碰撞适用于静态立面，是二维外轮廓沿 Z 轴挤出的薄体，不会从单张图片推断真实三维体积。轮廓内部的透明孔洞不作为通道保留；门洞、可穿越拱门等应关闭自动碰撞，按玩法单独添加碰撞体。细碎素材可改用「可见边界矩形」以减少物理开销。完全透明的图片不会生成碰撞。

运行时可从 Godot 的「调试 → 可见碰撞形状」检查匹配情况。自动节点为内部生成节点，不写回模板文件，避免保存重复碰撞。

## 初始示例场景配置（历史记录）

- `Ground`：使用 `G01_完整无透视地面贴图-20261025.png`，12 × 16 米的 XZ 平面；匹配可见边界的地面碰撞顶面位于 Y = 0。
- `Elements/ExampleColumn`：使用 `A05_前景左石柱-v2.png`，默认下中中心点；每像素 0.005 米，约 8.4 米可见高度。
- `Camera3D`：固定视角透视相机，向下 30°，视野 42°。立面固定朝向 +Z，不随摄像机旋转，确保显示与碰撞一致。
- `Sun`：暖色方向光，开启阴影。
- `WorldEnvironment`：使用 `assets/sky.png` 的 `PanoramaSkyMaterial` 天空与柔和环境光。天空是无限远环境，无需额外球体网格。

当前 `sky.png` 为 2816 × 1584 普通画幅，并非无缝等距柱状全景图；当前固定视角可以直接使用，自由环视可能出现接缝和拉伸。后续如需完整环视，在 Sky Material 的 Panorama 字段替换成无缝全景贴图即可。参考 [Godot PanoramaSkyMaterial 文档](https://docs.godotengine.org/en/stable/classes/class_panoramaskymaterial.html)。

原始素材保留在 assets 中；模板、脚本与主场景均独立于原始图片。

## 验证

使用 Godot 4.7.2 运行：

```text
godot --headless --path . --script res://tests/test_scene_element.gd
```

验证内容包括：九个中心点 × 四种镜像组合、非等比缩放、透明留白、自定义中心偏移、空贴图、全透明贴图、碰撞开关、实例隔离，以及主场景地面/石柱的物理射线检测。

`tests/capture_preview.gd` 可在具备图形显示的环境中生成 `docs/main_preview.png`。
