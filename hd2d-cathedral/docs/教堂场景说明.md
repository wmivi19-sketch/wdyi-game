# 参考图教堂场景

打开 `res://scenes/cathedral.tscn` 编辑，按 F6 预览；项目启动入口 `main.tscn` 已实例化此场景，按 F5 即可运行。

之前手动搭建的场景完整保存在 `res://scenes/main_before_reference_20261026.tscn`。原始 PNG 未修改。

## 场景结构

本场景按提供的 1672 × 941 参考图进行构图，使用 90 个独立模板实例、89 张现有元素贴图。采用固定透视相机、三维地面和朝向相机的二维素材，保留素材自带的光影与细节。

| 节点 | 内容 |
| --- | --- |
| Ground | 连续地面，中央红金纹样通道及两侧细石砖，完整地面碰撞 |
| SanctuaryPlatform | 抬高的祭坛平台，独立三维碰撞 |
| Elements/Architecture | 后方主墙、侧廊墙、顶部尖拱 |
| Elements/Windows | 三扇后墙彩窗及两侧彩窗 |
| Elements/Columns | 前、中、后三对石柱 |
| Elements/Altar | 台阶、红金地毯、白石祭坛、尖顶圣龛、红袍圣像、圣器及六支台面蜡烛 |
| Elements/Pews | 左右各七排长椅，中央保持通行空间 |
| Elements/Statues | 后墙壁龛与两侧白石壁龛、雕像和花台 |
| Elements/Banners | 八面蓝金旗帜 |
| Elements/Candles | 落地烛台与壁灯 |
| Elements/Flowers | 祭坛、台阶、彩窗及前景花艺 |
| Elements/Railings | 前景与侧廊木栏杆 |
| Atmosphere | 四条柔和光束、五处彩窗投影 |
| ColorFinish | 轻微高光柔化与暗角，可隐藏此节点关闭效果 |

所有元素均可在检查器中更换贴图、修改位置、大小、中心点、镜像和 Tint 颜色。石柱、长椅、烛台及栏杆使用自动边界碰撞；旗帜、彩窗、花饰等装饰关闭碰撞，避免阻挡通道。台阶为视觉素材，平台有独立碰撞。启动场景 main.tscn 已加入可移动、跳跃及换图的 TestPlayer，详见《人物测试说明.md》；目前通过跳跃登上平台，没有自动楼梯攀爬逻辑。

## 构图与后续编辑

相机位于 `(0,18,32)`，俯角 28°，FOV 45°。元素为与该相机对齐的三维卡片，适合固定视角的 HD-2D 游戏。当前素材的正面视角、绘制细节与参考图并不完全相同，因此这是利用现有分件素材重建的场景，不是参考图的逐像素复刻。自由绕行摄像机需要补充建筑侧面或三维模型。

建议直接编辑 `cathedral.tscn` 中的节点。`main.tscn` 是启动入口；打开其引用的原始场景即可编辑所有分组。

`tools/build_cathedral.py` 保存了初始布局参数，`docs/cathedral_layout.json` 记录各元素所用素材和参考区域。运行生成脚本会重建 `cathedral.tscn`，因此手动编辑后不要直接运行它，除非已备份手动修改。

## 验证结果

Godot 4.7.2：模板回归测试 159 项、教堂场景检查 317 项，全部通过。检查包含九宫格中心、镜像和缩放、所有元素引用、参考构图位置、碰撞生成、中央通道射线及祭坛平台碰撞。使用 OpenGL Compatibility 实际渲染并检查了 `docs/main_preview.png`。

```text
godot --headless --path . --script res://tests/test_cathedral.gd

```
